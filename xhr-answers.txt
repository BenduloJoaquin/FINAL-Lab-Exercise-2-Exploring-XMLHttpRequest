**Lab Exercise 2 – Exploring XMLHttpRequest**

**1. What is the difference between readyState and status in XMLHttpRequest?**

The readyState tells the current stage of the request, while status tells the HTTP response code from the server. For example, status 200 means the request was successful.

**2. How can you make the request asynchronous?**

You can make the request asynchronous by setting the third parameter of xhr.open() to true.

**3. Why is asynchronous communication recommended for web applications?**

Asynchronous communication is recommended because it allows the webpage to continue working while waiting for data from the server. It makes the website faster and provides a better user experience.
